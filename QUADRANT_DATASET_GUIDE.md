# 🎯 Квадрантный датасет - Руководство

## Что такое квадрантный датасет?

Квадрантный датасет (Quadrant Dataset) - это специальный режим генерации датасета, который разделяет каждое изображение на **4 квадранта** и применяет к каждому квадранту **разные цели оптимизации** при встраивании водяного знака.

## 📊 Зачем это нужно?

Различные части изображения имеют разные характеристики:
- **Гладкие области** - легко встраивать, но заметны артефакты
- **Текстурированные области** - сложнее встраивать, но артефакты менее заметны
- **Края и границы** - важны для визуального качества
- **Детализированные области** - требуют особого подхода

Применяя разные цели к разным квадрантам, мы можем:
1. Сравнить эффективность разных стратегий встраивания
2. Обучить классификаторы выбирать оптимальную стратегию
3. Создать датасет для исследования компромиссов качество/робастность

## 🔧 Как это работает

### Разделение изображения

```
┌─────────────┬─────────────┐
│             │             │
│ Квадрант 1  │ Квадрант 2  │
│    (Q1)     │    (Q2)     │
│             │             │
├─────────────┼─────────────┤
│             │             │
│ Квадрант 3  │ Квадрант 4  │
│    (Q3)     │    (Q4)     │
│             │             │
└─────────────┴─────────────┘
```

### Цели оптимизации

Каждый квадрант оптимизируется по своей цели:

| Квадрант | Цель | Приоритет |
|----------|------|-----------|
| **Q1** | Цель 1 | Например: максимальная робастность |
| **Q2** | Цель 2 | Например: максимальное качество |
| **Q3** | Цель 3 | Например: баланс качество/робастность |
| **Q4** | Цель 4 | Например: минимальные изменения |

(Конкретные цели определяются в коде функции `embed_quadrants_with_objectives`)

## 💡 Применение датасета

### 1. Обучение классификаторов

Использовать для обучения моделей, которые:
- Определяют оптимальную цель для каждой области изображения
- Предсказывают какая стратегия даст лучший результат
- Балансируют качество и робастность

### 2. Сравнение стратегий

Сравнить визуально и количественно:
- Какая цель даёт лучшее качество?
- Какая цель даёт максимальную робастность?
- Какие компромиссы между целями?

### 3. Исследование характеристик

Анализировать:
- Как разные области изображения реагируют на встраивание?
- Где артефакты более/менее заметны?
- Какие текстуры лучше скрывают водяной знак?

## 🔧 Настройка целей

Цели оптимизации настраиваются в коде:

**Файл**: [launch.cpp](GRADIENT_BASED_OPTIMIZER/src/launch.cpp)
**Функция**: `embed_quadrants_with_objectives()`

Пример структуры:

```cpp
void embed_quadrants_with_objectives(const string& image_path, const string& output_path) {
    // Загрузить изображение
    Mat img = imread(image_path);

    // Разделить на 4 квадранта
    int h = img.rows / 2;
    int w = img.cols / 2;

    Mat q1 = img(Rect(0, 0, w, h));       // Верхний левый
    Mat q2 = img(Rect(w, 0, w, h));       // Верхний правый
    Mat q3 = img(Rect(0, h, w, h));       // Нижний левый
    Mat q4 = img(Rect(w, h, w, h));       // Нижний правый

    // Применить разные цели к каждому квадранту
    embed_with_objective(q1, "objective1");
    embed_with_objective(q2, "objective2");
    embed_with_objective(q3, "objective3");
    embed_with_objective(q4, "objective4");

    // Сохранить результаты
    // ...
}
```

## 🎯 Примеры целей оптимизации

Возможные цели для каждого квадранта:

### Цель 1: Максимальная робастность
- Минимизировать изменения после JPEG сжатия
- Устойчивость к атакам
- Может снизить визуальное качество

### Цель 2: Максимальное качество
- Минимальные визуальные искажения
- Высокий PSNR/SSIM
- Может снизить робастность

### Цель 3: Баланс
- Компромисс между качеством и робастностью
- Адаптивная стратегия
- Универсальный подход

### Цель 4: Адаптивная
- Выбор стратегии в зависимости от содержимого
- Анализ текстур и характеристик блока
- Использование классификатора

## 🐛 Устранение проблем

### Эксперимент слишком долгий

**Решение**: Уменьшить количество изображений
```bash
# Обработать только 5 изображений
cd images
mkdir ../images_backup
mv *.png ../images_backup/
cp ../images_backup/lenna.png .
cp ../images_backup/aerial.png .
cp ../images_backup/baboon.png .
cp ../images_backup/boat.png .
cp ../images_backup/bridge.png .
cp ../images_backup/watermark.png .

# Запустить эксперимент
./run_experiment_with_telegram.sh --quadrant-dataset

# Восстановить изображения
mv ../images_backup/*.png .
```

### Датасет слишком большой для Telegram

**Решение**:
1. Архив разобьётся автоматически если >50MB
2. Или скачать напрямую:
   ```bash
   scp -r server:~/dataset_quadrant .
   ```

### Нехватка памяти

**Решение**: Обрабатывать изображения батчами:
```bash
# Разбить изображения на папки
mkdir batch1 batch2 batch3

# Обработать batch1
mv batch1/* images/
./run_experiment_with_telegram.sh --quadrant-dataset
mv dataset_quadrant dataset_quadrant_batch1

# Обработать batch2
mv batch2/* images/
./run_experiment_with_telegram.sh --quadrant-dataset
mv dataset_quadrant dataset_quadrant_batch2

# И так далее...
```
