# ✅ Чеклист переноса проекта

- [ ] Создать архив проекта или подготовить к git push
- [ ] Убедиться что включены все необходимые файлы:
  - [ ] Исходный код (GRADIENT_BASED_OPTIMIZER/)
  - [ ] Изображения (images/*.png)
  - [ ] Водяной знак (images/watermark.png)
  - [ ] Схемы встраивания (embedding_schemes.json)
  - [ ] Модели классификатора (*.pt файлы) - если используется
  - [ ] Скрипты (setup_environment.sh, deploy_and_run.sh)
  - [ ] Документация (*.md файлы)
- [ ] Проверить размер архива/данных
- [ ] Записать конфигурацию системы (версии библиотек и т.д.)

### Команда для создания архива
```bash
tar -czf gradient_optimizer_transfer.tar.gz \
  --exclude='build' \
  --exclude='dataset*' \
  --exclude='*.o' \
  --exclude='*.log' \
  .
```

## 🔧 Установка окружения на новом компьютере

### Проверка системы

- [ ] Операционная система: Linux/Ubuntu 20.04+ или macOS
- [ ] Права sudo доступны
- [ ] Интернет соединение работает
- [ ] Достаточно места на диске:
  - [ ] Минимум 1 GB для базовой установки
  - [ ] Минимум 2 GB для установки с PyTorch

### Запуск установки

- [ ] Перейти в директорию проекта: `cd GRADIENT_BASED_OPTIMIZER`
- [ ] Сделать скрипты исполняемыми: `chmod +x *.sh`
- [ ] Выбрать режим установки:

**Базовая установка (без классификатора):**
```bash
./setup_environment.sh
```
- [ ] Установка запущена
- [ ] Установлен CMake
- [ ] Установлен GCC/компилятор
- [ ] Установлен OpenCV
- [ ] Установка завершена успешно

**Полная установка (с классификатором):**
```bash
./setup_environment.sh --with-pytorch
```
- [ ] Установка запущена
- [ ] Установлены базовые компоненты (см. выше)
- [ ] PyTorch загружен (~200MB, может занять время)
- [ ] PyTorch распакован в ~/libtorch
- [ ] Переменные окружения настроены
- [ ] Установка завершена успешно

### Проверка установки

- [ ] Выполнить: `source ~/.bashrc` (если устанавливали PyTorch)
- [ ] Проверить CMake: `cmake --version` (должен быть 3.16+)
- [ ] Проверить GCC: `g++ --version` (должен быть 9.0+)
- [ ] Проверить OpenCV: `pkg-config --modversion opencv4`
- [ ] Проверить PyTorch: `ls ~/libtorch` (если устанавливали)
