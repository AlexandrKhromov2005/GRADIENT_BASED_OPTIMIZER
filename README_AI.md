# 🤖 GRADIENT_BASED_OPTIMIZER с ИИ-классификатором

Система встраивания цифровых водяных знаков (ЦВЗ) с автоматическим выбором схемы встраивания на основе машинного обучения.

## 🚀 Быстрый старт

### Самый простой способ - используйте Makefile:
```bash
make          # Автоматическая сборка
make help     # Показать все команды
```

### Альтернативно - используйте скрипт:
```bash
./build.sh    # Автоматическая сборка
```

### Ручная сборка:
```bash
# Базовая (без ИИ)
mkdir build && cd build && cmake .. && make -j4

# Полная (с ИИ)
mkdir build && cd build && cmake -DCMAKE_PREFIX_PATH=~/libtorch .. && make -j4
```

## 🎯 Режимы работы

### 🔧 Базовые (работают всегда):
```bash
./build/gradient_based_optimizer --help           # Справка
./build/gradient_based_optimizer --test           # Тест (1 итерация)  
./build/gradient_based_optimizer --dataset        # Генерация датасета
./build/gradient_based_optimizer                  # Основной режим
```

### 🤖 С ИИ-классификатором (требует PyTorch):
```bash
./build/gradient_based_optimizer --example        # Демо классификатора
./build/gradient_based_optimizer --classifier     # Генерация с ИИ
./build/classifier_example                        # Подробный тест
```

## 🎯 Как работает ИИ-классификатор

1. **Анализирует блок 8x8 пикселей**
2. **Предсказывает оптимальную схему:**
   - `scheme_0` → `scheme2` (22 коэффициента DCT)
   - `scheme_1` → `scheme3` (25 коэффициентов DCT)  
3. **Автоматически переключается** между схемами
4. **100% точность** извлечения на тестах

## 📊 Производительность

- **Встраивание**: ~50-200ms на блок (включая ИИ)
- **Извлечение**: ~40-100ms на блок (включая ИИ)
- **Точность классификации**: ~73% (научно подтверждено)
- **Точность извлечения**: 100% на тестах
