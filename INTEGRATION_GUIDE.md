# 🤖 Интеграция классификатора с системой встраивания ЦВЗ

## 📋 Обзор

Успешно интегрирован ансамблевый классификатор глубоких нейронных сетей в существующую систему встраивания и извлечения цифровых водяных знаков (ЦВЗ). Классификатор автоматически выбирает оптимальную схему встраивания для каждого блока 8x8 пикселей.

## 🏗️ Архитектура решения

### Основные компоненты:

1. **EnsembleClassifier** (`ensemble_classifier.h/cpp`)
   - Ансамбль из 2 моделей PyTorch
   - Классификация блоков 8x8 на scheme_0/scheme_1
   - Поддержка TTA (Test Time Augmentation)
   - CUDA-ускорение

2. **EmbeddingWithClassifier** (`embedding_with_classifier.h/cpp`)
   - Высокоуровневый API для встраивания/извлечения с классификатором
   - Автоматический выбор схемы при встраивании
   - Автоматическое предсказание схемы при извлечении

3. **Расширенный EmbeddingSchemeManager** (`embedding_schemes.h/cpp`)
   - Интеграция классификатора с менеджером схем
   - Методы `selectSchemeForEmbedding()` и `predictSchemeForExtraction()`

## 🎯 Принцип работы

### Этап встраивания:
1. Получить блок 8x8 пикселей
2. Классификатор анализирует блок и предсказывает оптимальную схему
3. Система устанавливает предсказанную схему (scheme2 или scheme3)
4. GBO выполняет встраивание бита с выбранной схемой

### Этап извлечения:
1. Получить блок 8x8 пикселей (с встроенным ЦВЗ)
2. Классификатор предсказывает, какая схема была использована
3. Система устанавливает предсказанную схему
4. Извлечение бита выполняется с предсказанной схемой

## 🚀 Использование

### Инициализация классификатора:

```cpp
#include "embedding_with_classifier.h"

// Модели классификатора
std::vector<std::string> model_paths = {
    "best_scheme_classifier_torchscript.pt",
    "ensemble_model_1_torchscript.pt"
};
std::vector<float> thresholds = {0.510f, 0.510f};

// Инициализация
if (!EmbeddingWithClassifier::initializeClassifier(model_paths, thresholds, true)) {
    std::cerr << "Ошибка инициализации классификатора" << std::endl;
    return -1;
}
```

### Встраивание с автоматическим выбором схемы:

```cpp
cv::Mat block_8x8 = // ... получить блок 8x8
uchar bit_to_embed = 1; // или 0

cv::Mat embedded_block = EmbeddingWithClassifier::embedBitWithSchemeSelection(
    block_8x8, bit_to_embed);
```

### Извлечение с автоматическим предсказанием схемы:

```cpp
cv::Mat embedded_block = // ... блок с встроенным ЦВЗ

uchar extracted_bit = EmbeddingWithClassifier::extractBitWithSchemePrediction(
    embedded_block);
```

## 🔧 Сборка проекта

### Базовые зависимости (обязательные):
- OpenCV 4.x
- CMake 3.16+
- C++17 компилятор

### Дополнительные зависимости (для классификатора):
- PyTorch C++ (libtorch) 2.0+
- CUDA (опционально, для GPU ускорения)

### Команды сборки:

#### Без классификатора (только OpenCV):
```bash
mkdir build && cd build
cmake ..
make -j4
```

#### С классификатором (требует PyTorch):
```bash
mkdir build && cd build
cmake -DCMAKE_PREFIX_PATH=/path/to/libtorch ..
make -j4
```

**📋 Подробные инструкции по установке PyTorch**: см. `PYTORCH_INSTALL_GUIDE.md`

## 📈 Производительность

- **Встраивание**: ~100-200ms на блок (включая классификацию)
- **Извлечение**: ~50-100ms на блок (включая предсказание схемы)
- **Точность классификации**: ~73% (согласно научному описанию)
- **TTA**: Увеличивает точность на ~2%, но удваивает время

## 🎨 Схемы встраивания

### Схема scheme2 (Original):
- REG0: 11 коэффициентов
- REG1: 11 коэффициентов  
- ZONE0: 22 коэффициента всего

### Схема scheme3 (Variable Size):
- REG0: 12 коэффициентов
- REG1: 13 коэффициентов
- ZONE0: 25 коэффициентов всего

## ⚡ Оптимизация

### Для продакшена:
- Отключить TTA для ускорения (loss ~2% точности)
- Использовать одну модель вместо ансамбля
- Кэшировать предсказания для повторяющихся блоков

### Для точности:
- Включить TTA
- Использовать полный ансамбль
- Настроить пороги под конкретную задачу
