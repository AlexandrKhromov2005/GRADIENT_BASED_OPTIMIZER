# 🚀 Эксперимент с final_model.pt - Быстрый старт

## ⚡ Быстрый запуск

```bash
# 1. Запуск эксперимента
./run_classifier_experiment.sh

# 2. Очистка результатов
./clean_experiment_results.sh
```

## 📊 Что делает эксперимент

Тестирует интеграцию модели `final_model.pt` в алгоритм встраивания водяных знаков:

1. **Загружает модель** `final_model_torchscript.pt`
2. **Обрабатывает изображения** из папки `images/`  
3. **Классифицирует блоки 8x8** как Scheme2 или Scheme3
4. **Встраивает водяные знаки** согласно выбору классификатора
5. **Извлекает и проверяет** корректность извлечения
6. **Выдает статистику** точности и выбора схем

## 📈 Ожидаемые результаты

- **Точность извлечения**: ~97.57%
- **Обработка**: ~12,000 блоков из 30 изображений
- **Время**: 2-30 минут в зависимости от режима

## 📁 Структура результатов

```
dataset_classifier/
├── scheme2_selected/      # Выбрана Scheme2 (Alternative)
├── scheme3_selected/      # Выбрана Scheme3 (Variable Size)  
├── extraction_correct/    # Правильное извлечение
└── extraction_incorrect/  # Ошибки извлечения
```

## 🎯 Режимы запуска

1. **Быстрый тест** (2-5 мин) - проверка работоспособности
2. **Полный эксперимент** (15-30 мин) - все изображения
3. **Ограниченный** (5-10 мин) - 5 изображений

## 📋 Требования

- Linux + g++ + cmake + OpenCV
- 2GB свободного места
- PyTorch загружается автоматически
